# **AI Interior 추천**

**사용자가 입력한 내용을 기반으로 인테리어 관련 키워드와 추천 스타일을 제공합니다.**
<br>
<br>

## 주요 기능
- 인테리어 스타일 키워드 검색
- 테마별 추천 키워드 제공
- 유효하지 않은 키워드 입력 시 예외 처리
- 로딩 및 에러 상태 처리
- Next.js API Route를 활용한 추천 데이터 제공
<br>

## 기술 스택
- Next.js
- React
- TypeScript
- Tailwind CSS
<br>
